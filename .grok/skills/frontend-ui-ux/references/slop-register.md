# Slop register

Use these entries after the craft-floor pass to find repeated defaults, filler, and fake functionality. A deterministic signal may identify a candidate, but a row marked JUDG or DET-assist needs a reviewer to decide whether the context earns an exception. Do not convert taste into an automatic HIGH. The probe can check live DOM and computed styles; the static fallback reports only source-visible signals and keeps all rendered checks `not_verified`.

When a row fires, remove the unnecessary element first, use a native platform control when possible, reuse an existing component or token, correct a value, and add new code only if none of those resolves the problem. Preserve genuine facts, credited data, and explicit design direction. A claimed fix is supported by a second probe at the affected view and the final responsive matrix.

The rule's condition must be observed in the same surface being judged. A stylesheet declaration that never runs can be Derived or advisory; do not report it as a user-observed animation. An attribute such as a dead link is Derived because an attached listener cannot be enumerated from in-page JavaScript. A page-wide cluster or brand rationale is Inferred.
