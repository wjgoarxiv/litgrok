# OWASP-oriented checklist

## Grok-native contract

The skill selector loads this checklist; approved checks use the native `start-work` handoff and a subsequent approved session. Results
remain `REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed evaluator or
budget requires re-planning and review.

Review authorization, authentication, sessions, validation, injection, design, configuration,
dependencies, cryptography, logging, server-side request controls, files, and failure behavior.
Missing evidence is `not assessed`, never `pass`.
