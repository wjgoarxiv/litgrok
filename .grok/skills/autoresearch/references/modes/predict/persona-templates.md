# Prediction perspective templates

## Grok-native contract

The skill selector loads these inert lenses; approved work runs through the native `start-work` handoff and a subsequent approved session.
Packets remain `REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed
evaluator or budget requires re-planning and review.

Useful lenses include base-rate, mechanism, adversarial skeptic, operator, and uncertainty auditor.
Each returns assumptions, evidence, forecast, confidence, disconfirmers, and unknowns. Lenses do not
select a model, grant tools, write shared files, or spawn descendants.
