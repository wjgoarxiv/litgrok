# 적용 범위

## 대상 설비와 사용자

이 절차서는 연구동 3층 공용 실험실 301호와 302호에 설치된 흄후드 6대(FH-301-1~3, FH-302-1~3)에 적용한다. 사용자는 공용 실험실 사용 승인을 받은 연구원과 학생 연구원이며, 승인 전 실험실 안전교육 2시간을 이수해야 한다. 개인 실험실의 흄후드와 생물안전작업대는 별도 절차서를 따른다.

::: sidebar title="용어"
**면속도**: 새시 개구부를 지나 흄후드 안으로 들어가는 공기의 평균 속도(m/s).

**새시**: 흄후드 앞면의 위아래로 움직이는 유리문. 작업 높이는 바닥에서 40cm다.

**배기 경보**: 면속도가 기준 아래로 떨어지면 울리는 소리와 표시등.
:::

흄후드는 실험 중 생기는 유해 증기를 실험자 쪽으로 새지 않게 빨아들여 옥상 배기구로 내보낸다. 이 기능은 면속도가 기준 범위 안에 있고 새시가 작업 높이 이하로 내려와 있을 때만 유지된다. 그래서 점검의 중심은 면속도와 새시 위치, 그리고 후드 안의 기류를 막는 물건이 없는지 확인하는 일이다.

## 책임

연구지원팀은 월간 풍속 측정, 연간 정밀 검사, 고장 수리 접수를 맡는다. 사용자는 사용 전 점검과 사용 후 정리를 맡는다. 점검 결과는 각 흄후드 옆에 붙은 점검표와 실험실 안전 관리 시스템에 함께 남긴다.

# 사용 전 점검

## 점검 순서

흄후드를 켜고 1분이 지난 뒤 다음 순서로 점검한다. 한 항목이라도 기준을 벗어나면 실험을 시작하지 않고 4장의 조치를 따른다.

1. 전원 스위치를 켜고 조명과 배기 팬이 함께 작동하는지 확인한다.
2. 표시창의 면속도가 0.4~0.6m/s 범위 안에 있는지 읽는다.
3. 새시를 작업 높이 40cm까지 올렸다가 내리며 걸림이 없는지 본다.
4. 후드 안쪽 뒷면 배기 슬롯 앞 15cm 안에 시약병이나 장비가 없는지 확인한다.
5. 작업대 위에 쏟은 시약 자국이 있으면 사용 전에 닦고 점검표에 적는다.
6. 점검표에 날짜, 이름, 면속도 값을 적고 서명한다.

::: callout kind=warning title="경보가 울릴 때"
배기 경보가 울리면 진행 중인 작업을 멈추고 용기 뚜껑을 닫은 뒤 새시를 끝까지 내린다. 경보를 끄거나 테이프로 표시등을 가리지 않는다. 실험실 밖으로 나와 연구지원팀(내선 3150)에 알리고, 조치가 끝날 때까지 해당 흄후드에 사용 금지 표지를 건다.
:::

## 작업 중 지켜야 할 사항

작업은 새시 면에서 15cm 이상 안쪽에서 한다. 머리를 후드 안으로 넣지 않으며, 새시를 작업 높이보다 올린 채 자리를 비우지 않는다. 후드 안에 큰 장비를 둘 때는 받침대를 써서 바닥과 장비 사이에 5cm 정도 틈을 두어 기류가 장비 밑으로 지나가게 한다. 가열판과 같은 열원은 기류를 흐트러뜨리므로 후드 중앙 뒤쪽에 둔다. 산과 휘발성 유기 용매를 쓰는 작업은 한 후드 안에서 동시에 하지 않으며, 둘을 이어서 해야 하는 날에는 연구지원팀과 미리 협의해 후드별 사용 시간표를 정하고 그 내용을 점검표 비고란에 적어 다음 사용자도 알 수 있게 한다.

## 사용 후 정리

1. 사용한 시약과 폐액 용기의 뚜껑을 닫아 지정 보관장으로 옮긴다.
2. 작업대를 물티슈나 지정 세척제로 닦는다.
3. 새시를 끝까지 내린다.
4. 다음 사용자가 30분 안에 없으면 조명을 끄고 배기 팬은 그대로 둔다.

배기 팬은 야간에도 끄지 않는다. 팬을 끄면 후드 안에 남은 증기가 실험실로 퍼질 수 있고, 다시 켰을 때 면속도가 안정되기까지 3분 정도가 걸린다.

# 월간 풍속 측정

## 측정 준비

측정은 연구지원팀 담당자가 매월 첫째 주 화요일 오전에 한다. 측정 전날 실험실 게시판과 메일로 측정 시간을 알리고, 측정 시간에는 해당 흄후드를 쓰지 않도록 사용 예약을 막는다. 열선 풍속계는 연 1회 교정을 받은 것을 쓰고, 교정 만료일을 측정 기록에 함께 적는다.

## 측정 방법

1. 새시를 작업 높이 40cm에 맞추고 후드 안의 물건을 모두 꺼낸다.
2. 개구부를 가로 3칸, 세로 2칸으로 나눠 6개 지점을 정한다.
3. 각 지점 중앙에서 풍속계 탐침을 새시 면과 같은 높이에 두고 10초간 평균값을 읽는다.
4. 6개 값의 평균을 면속도로 기록하고, 가장 낮은 값과 가장 높은 값도 함께 적는다.
5. 표시창 값과 측정 평균의 차이가 0.05m/s를 넘으면 표시창 보정을 요청한다.

# 이상 시 조치

## 판정 기준과 조치

표 3. 이상 유형별 조치 (예시)

| 이상 유형 | 1차 조치 | 연락처 | 재사용 조건 |
| --- | --- | --- | --- |
| 면속도 0.4m/s 미만 | 사용 중지, 표지 부착 | 연구지원팀 3150 | 재측정 적합 |
| 면속도 0.6m/s 초과 | 사용 가능, 신고 | 연구지원팀 3150 | 다음 월간 측정 |
| 배기 경보 | 작업 중지, 새시 닫기 | 연구지원팀 3150 | 원인 제거, 재측정 |
| 새시 걸림 | 사용 중지 | 시설팀 3200 | 수리 완료 |
| 시약 유출 | 유출 키트 사용 | 안전관리실 3119 | 정화 확인 |

면속도가 기준보다 높은 경우에는 바로 위험하지는 않지만, 새시 가장자리에서 기류가 소용돌이쳐 오히려 증기가 밖으로 새는 일이 생긴다. 신고를 받으면 연구지원팀이 다음 월간 측정 전에 댐퍼를 조정한다.

## 수리 후 재사용

수리나 조정이 끝나면 연구지원팀 담당자가 3장의 측정 방법으로 면속도를 다시 잰다. 결과가 적합이면 사용 금지 표지를 떼고 수리 이력 대장과 안전 관리 시스템에 수리 내용, 측정값, 재사용 일시를 적는다. 같은 흄후드에서 3개월 안에 같은 이상이 두 번 생기면 외부 검사 기관에 정밀 검사를 의뢰한다.
