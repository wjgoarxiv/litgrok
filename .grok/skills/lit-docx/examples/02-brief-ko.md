현행 메신저 계약을 연장하지 않고 2027년 3월 말까지 그룹웨어 내장 메신저(안 2)로 전환하는 안, 그리고 전환 비용 3,200만 원(예시)을 2026년 4분기 정보화 예비비에서 집행하는 안의 승인을 요청한다.
:::

# 요약

안 2로 전환하면 3년간 1억 1,400만 원을 아낀다. 현행 메신저를 3년 더 쓰는 비용은 2억 400만 원이고, 그룹웨어 내장 메신저는 전환비를 포함해 9,000만 원이다(예시).

기능 손실은 크지 않다. 직원 1,240명의 최근 6개월 사용 기록을 보면 대화, 파일 전송, 화상 통화가 전체 사용의 96%를 차지하며, 세 기능 모두 내장 메신저에 있다.

보안 요건도 충족한다. 내장 메신저는 사내 서버에 대화를 저장하고, 2026년 8월 보안 진단에서 지적 사항 없이 통과했다.

위험은 전환 기간의 혼선이다. 대화 기록 이관과 외부 협력사 계정 재발급에 6주가 걸리므로, 2027년 1월 첫 주에 착수해야 3월 말 계약 만료 전에 끝난다.

# 검토 배경

- 현행 메신저 계약 만료일 2027. 3. 31., 연장 시 사용료 연 18% 인상 통보 받음
- 그룹웨어는 2025년 교체 때 메신저 기능을 포함해 계약, 현재 사용하지 않는 상태
- 두 메신저를 함께 쓰는 부서가 생겨 업무 요청 누락 사례가 분기마다 보고됨
- 2026년 7월 경영진 회의에서 메신저 일원화 검토를 지시

# 대안 비교

표 1. 대안별 3년 비용과 주요 특성 (예시)

| 구분 | 안 1 현행 연장 | 안 2 그룹웨어 내장 | 안 3 신규 도입 |
| --- | ---: | ---: | ---: |
| 3년 사용료 (만 원) | 20,400 | 5,800 | 13,500 |
| 전환비 (만 원) | 0 | 3,200 | 4,600 |
| 3년 합계 (만 원) | 20,400 | 9,000 | 18,100 |
| 대화 서버 위치 | 외부 | 사내 | 외부 |
| 전환 기간 | 없음 | 6주 | 10주 |

자료: 업체 견적(2026. 9.), 정보전략팀 산출

- 안 1은 전환 부담이 없으나 비용이 가장 크고, 인상분이 매년 반복될 가능성 있음
- 안 2는 비용이 가장 적고 대화가 사내 서버에 남음. 화면 공유 중 원격 제어 기능은 없으나 사용 비중 0.4%로 원격 지원 도구로 대체 가능
- 안 3은 기능이 가장 많으나 비용과 전환 기간 모두 안 2보다 불리함

# 전환 일정과 위험

## 추진 일정

- 2027년 1월 1주: 전환 공지, 부서별 담당자 지정
- 2027년 1월 2~4주: 최근 1년 대화 기록 이관, 협력사 계정 380개 재발급
- 2027년 2월: 두 메신저 병행 운영, 현행 메신저는 읽기 전용으로 전환
- 2027년 3월 2주: 현행 메신저 종료, 3월 말 계약 만료

## 위험 대응

- 대화 기록 이관 누락: 이관 전후 건수를 부서별로 대조하고, 원본은 계약 만료 후 1년간 보관
- 협력사 계정 재발급 지연: 협력사별 담당자 목록을 12월 중 먼저 확보
- 병행 기간의 요청 누락: 2월부터 업무 요청은 내장 메신저로만 받도록 부서장 회의에서 공지
