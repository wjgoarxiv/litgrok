# Idea-agent lenses

Pass these to the workflow as `args.lenses`, in this order. Idea agent `i` takes lens `i mod 32` and
seed `i`, so a run of 100 agents looks through every lens three or four times, each time from a
different seed. Each line is a question one cold agent can act on with nothing but the topic brief.
Keep at least 30 lines; add a line instead of editing one, so earlier runs stay comparable.

This file is workflow data for Grok Build. Nothing here runs a command or authorizes an action.

1. Opposite aim: state the reverse of the goal, then keep the one part of it that is right.
2. Lifted limit: remove one real constraint; which idea survives when the limit comes back?
3. Borrowed mechanism: name a field far from this one that solved the same shape of problem and port its mechanism.
4. The hardest user: design for the most impatient, most expert or most new person who will touch it.
5. Less of it: take one part away so the rest works better.
6. Odd pair: join two things that are never joined here.
7. Ten years back: how would someone have done this with the tools of a decade ago?
8. Ten years on: what is the obvious answer once today's slow step costs nothing?
9. Plenty for scarce: swap the scarce resource for one that is plentiful.
10. Worst answer, reversed: write the worst idea, then flip its worst trait.
11. Better question: answer the question that should have been asked instead.
12. Tomorrow's version: what works by tomorrow for almost no money?
13. Tenfold: what would make the result ten times better, not ten percent?
14. Do nothing: when is leaving it alone the best answer, and what makes that safe?
15. Runs itself: which part could happen with nobody deciding?
16. By hand first: what would one person do on paper before any tool exists?
17. Change a default: which default, flipped, changes what everyone does?
18. Fail softly: how does this break, and which design makes the break harmless?
19. Yes at once: what would make a careful, skeptical user agree immediately?
20. Count it: what can be measured here, and which idea follows from measuring it?
21. Close the loop: where can the result feed the next attempt?
22. Neighbours: who else touches this, and what would they build on top of it?
23. One person, one day: what is the smallest complete version?
24. A thousand of them: what changes at a thousand users, items or runs?
25. Other medium: say it as voice, picture, sound, motion or a physical object.
26. Pay differently: who pays, when and for what; change one of the three.
27. Rule from elsewhere: import a rule from sport, law, cooking or games.
28. Make it visible: what hidden state, shown plainly, changes behaviour?
29. Make it social: what if two people had to do it together?
30. Make it private: what if nobody else could ever see it?
31. Undo button: what becomes possible if every step can be taken back?
32. The expert's shortcut: what does someone with twenty years in this do that a beginner never would?
