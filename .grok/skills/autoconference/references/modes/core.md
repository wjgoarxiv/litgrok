# Autoconference core mode

## Grok-native contract

The skill selector loads this guidance. After approval, hand work to the native `start-work` handoff and a subsequent approved session;
this family does not define or inspect host lifecycle state. Every artifact/status is
`REVIEW_REQUIRED`, and the package cannot programmatically claim family completion. Changed evaluator
or budget requires re-planning and review.

Require real collaboration or return `BLOCKED_MULTI_AGENT_UNAVAILABLE`.
Children return packets; only the root writes conference files. Children are read-only and packet-only, cannot spawn descendants,
and cannot alter shared/product files or authority. Root validates identity, schema, scope, evidence,
uncertainty, and cleanup.

Use the host's built-in `explore` and `general-purpose` subagents for bounded packets. Track their
state in the tasks pane or `/tasks`; those surfaces do not select a model, grant writes, or create a
child-to-child channel. If the required collaboration surface is unavailable, return
`BLOCKED_MULTI_AGENT_UNAVAILABLE`.

Root orders independent research packets, poster comparison, independent review, knowledge transfer,
and a synthesis candidate. Synthesis, round counts, event text, process files, and consensus are
evidence only. `BUDGET_EXHAUSTED` is non-success. All outcomes remain `REVIEW_REQUIRED`; only human
review plus the host workflow can decide next steps.

Optional plotting uses `<loaded-autoresearch-skill-dir>/scripts/style_presets.py --check` and may return
`BLOCKED_OPTIONAL_MATPLOTLIB_UNAVAILABLE` without installation.
