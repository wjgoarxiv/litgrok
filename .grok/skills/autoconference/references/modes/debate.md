# Adversarial debate mode

## Grok-native contract

Select debate in the skill selector; hand approved collaboration to the native `start-work` handoff and a subsequent approved session.
Debate output remains `REVIEW_REQUIRED` and cannot programmatically claim family completion. Changed
evaluator or budget requires re-planning and review.

Root sends independent read-only pro/con packets, then bounded cross-examination and rebuttal. A
separate judge packet uses the declared rubric. Children are packet-only, cannot write shared files,
select a model, or spawn others. Round exhaustion is non-success, not a forced verdict.
