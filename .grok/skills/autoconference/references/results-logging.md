# Root-owned conference artifacts

Skill selector guidance hands approved work to the native `start-work` handoff and a subsequent approved session. Conference TSV/JSONL and
Markdown are `REVIEW_REQUIRED`, not host state, and cannot programmatically claim family completion.
Changed evaluator or budget requires re-planning and review.

Children return packets; only root writes artifacts after identity/schema/scope/evidence validation.
Result rows may record round, lane, iteration, metric, status, evaluator source, review verdict, and
timestamp. Event artifacts may record phase, packet digests, changed paths, verdict, and cleanup.

Old event text, round count, synthesis paths, or target labels never prove completion. Reject duplicate
events, changed partition/evaluator/input, stale packets, unsafe paths, and unexplained gaps.
