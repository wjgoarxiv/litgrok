# Code of conduct

Be respectful and specific in issues, reviews, and project discussions. Critique code and evidence rather than people. Welcome questions, explain assumptions, and respect differing experience and communication styles.

Harassment, threats, discrimination, personal attacks, sexualized conduct, and disclosure of another person's private information are unacceptable. Do not publish private messages or credentials in a report.

Maintainers may edit or remove harmful content, close disruptive discussions, or restrict participation. Responses should consider the severity and context; repeated or serious violations may result in exclusion. Maintainers follow the same expectations.

For a concern, use an available private repository reporting channel. If none is displayed, ask for a private maintainer contact using a minimal issue without identifying or sensitive details. No unverified contact address or guaranteed response time is provided. These expectations apply to project spaces and to people representing the project publicly.
